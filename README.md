# learning-repo

Interactive TriageMate Deep Textbook and Engineering Masterclass.

Live GitHub Pages URL: https://gokublack29.github.io/learning-repo/

## Course Contents

- `index.html`: Full interactive web app (54-commit time machine, 6 entry points, interactive 5-stage pipeline & logit calculator, Chart.js leaderboard, 28 Q&As + quiz).
- `lesson_01_foundations_zero_to_one.html`: Zero-to-one foundations + SVG architecture diagram + self-check drill.
- `lesson_02_recursive_54_commits.html`: Complete table of all 54 commits in recursive backtracking order (#54 -> #1).
- `lesson_03_all_entry_points.html`: All 6 entry points with exact CLI commands and call-graph targets.
- `lesson_04_end_to_end_data_flows.html`: Line-by-line annotated code walkthroughs (`sink_finder.py`, `engine.py`, `decision.py`) + numerical stability drill.
- `lesson_05_decisions_and_consequences.html`: All 6 architectural pivots and empirical consequences.
- `lesson_06_evaluation_gates_and_math.html`: L0/L2/L3 gates, `P@90R`, `ECE`, `Within-Rule AUC`, and full leaderboard.
- `lesson_07_interview_prep_guide.html`: Interactive interview defense drills.
