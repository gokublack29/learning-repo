Lesson 03 • Complete Entry Point & Execution Map

Every Entry Point Into the TriageMate Codebase

Depending on whether you are triaging a Semgrep JSON file, scanning a Java repo inside Docker, calling the Hugging Face Python API, training QLoRA adapters, or reproducing benchmark numbers on CPU, execution enters through one of these 6 paths.

1. d1_triage.py / python -m d1_triage → d1_triage/cli.py:main()

Commit 5bb181f

Primary sub-15ms developer CLI. Flags: --demo, --scan <semgrep.json>, --benchmark {ghsa,vul4j}, --limit N, --cpu, --gpu, --mock, --threshold 0.5, --output/-o, --model.

python d1_triage.py --scan semgrep-findings.json --threshold 0.5 -o triage-report.json

2. pyproject.toml [project.scripts] triagemate → triage/cli.py:main()

Commit 14f6e76 / d85a712

Full repository scanner & pluggable scorer. Invokes run_semgrep(target_dir, out_json), extracts code windows via findings_from(), and routes to --scorer {model, decision, heuristic}.

triagemate /path/to/java/repo --scorer decision --decision-model Qwen/Qwen3.5-4B --json out.json

3. Dockerfile ENTRYPOINT ["triagemate"]

Commit 645bd4c

Containerized runtime on python:3.12-slim bundling openjdk-17-headless, semgrep, and deterministic uv sync --frozen --no-cache using uv.lock.

4. LiquidAI/d1-3B Python SDK (model.system_one_batch)

Direct Hugging Face Transformers call using trust_remote_code=True and QUESTIONS = {"tp": {"type": "noul", "instructions": QUESTION, "criteria": CRITERIA}}.

5. training/launch.py, runner.py, train_qlora.py & evaluate_llm.py

Multi-GPU / Kaggle training pipeline: pulls HF datasets (0772aa7), enforces T4 fp16 fallback (3678145), trains LoRA r=16, alpha=16 on 7 linear projections, samples errors (errors.py), and builds Markdown reports (report.py).

6. audit/evaluate_d1.py, audit/test_whole_suite.py & pytest (tests/test_*.py)

Zero-dependency CPU reproduction (<0.2s) of all L0/L2/L3/Vul4J benchmark scores (19 assertions) plus 8 pytest unit test files covering CLI, AST dataset, decision scorer, metrics, prompts, explain, scan IDs, and verify.
