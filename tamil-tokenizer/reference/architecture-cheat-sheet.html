Tamil Tokenizer Architecture Sheet

Cheat sheet of runnable CLI commands, core modules, and data flow paths.

CLI Commands

# 1. Encode text via CLI
cargo run --release --bin encode output/tamil_tokenizer.json "வணக்கம் உலகம்"

# 2. Interactive prompt
cargo run --bin main output/tamil_tokenizer.json

# 3. Train from corpus
cargo run --release --bin train data/tamil_corpus.txt 50000 output/tamil_tokenizer.json 1

# 4. Export to Hugging Face format
cargo run --release --bin export_hf output/tamil_tokenizer.json output/hf_model/

Core Engine Modules

  • lib.rs: Crate root, exposes public API, exports load_tokenizer.
  • vocab.rs: Builds base seed vocabulary (1,135 tokens including Tamil letters, vowel signs, conjuncts, and raw bytes).
  • pretokenizer.rs: Splits input text into word chunks using regex.
  • trainer.rs: Learns BPE merges across CPU threads using Rayon and bit-packed 64-bit pair keys.
  • encoder.rs: Fast greedy BPE encoder using priority merge ranks.

Data Flow Summary

[Raw Text Corpus]
       │
       ▼
[pretokenizer.rs] ──> Splits text into words using regex
       │
       ▼
  [trainer.rs]    ──> Counts adjacent pairs, merges top pair, repeats N times
       │
       ▼
 [tokenizer.json] ──> Saves vocab map {token: id} and merge pairs
       │
       ▼
  [encoder.rs]    ──> Maps new text to base tokens, applies merges -> Vec<u32>
