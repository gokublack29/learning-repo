Lesson 0002

Tamil Orthography and Conjunct Stems

Why Tamil letters combine like Lego bricks, and why this tokenizer pre-builds 528 combinations before training starts.

Step 2 of 13. Orientation. Why Tamil needs its own tokenizer at all.

1. English Alphabet vs. Tamil Abugida

In English, letters sit in a simple row: c + a + t = cat. Each character stands alone.

Tamil is an abugida (syllabic alphabet). Letters combine visually and phonetically into composite units. To understand this repo, you only need four building blocks:

1
Independent Vowels (12 letters)

Standalone vowel sounds used only when a word begins with a vowel.

அ (a), ஆ (aa), இ (i), ஈ (ee), உ (u), ஊ (oo)...

Example: The word அம்மா (Amma) begins with the independent vowel அ.

2
Consonants and the Pulli (Dot)

Every Tamil consonant naturally carries a built-in short "a" sound: க is pronounced "ka", ப is "pa".

To make a pure consonant without a vowel, Tamil adds a dot called a pulli (virama) on top:

க (ka) + ் (pulli) = க் ("k" sound)
ப (pa) + ் (pulli) = ப் ("p" sound)
3
Vowel Signs (12 signs)

When a vowel sound follows a consonant inside a word, you do not write the independent vowel. You attach a vowel sign (maatra) to the consonant.

க (ka) + ா (aa sign) = கா ("kaa")
க (ka) + ி (i sign) = கி ("ki")
க (ka) + ு (u sign) = கு ("ku")
4
Two-Consonant Conjunct Stems (C1 + ் + C2)

In Tamil, consonants frequently cluster together with a pulli in the middle. This cluster is a conjunct stem:

ண (na) + ் + ட (da) = ண்ட (as in வண்டு / insect)
த (ta) + ் + த (ta) = த்த (as in புத்தகம் / book)
க (ka) + ் + க (ka) = க்க (as in அக்கா / sister)
ந (na) + ் + த (ta) = ந்த (as in சந்தை / market)

2. Why This Matters for Tokenization and Rust

Computers store text as UTF-8 bytes. Look at what happens under the hood for ண்ட:

The Unicode byte reality:

  • ண = 3 bytes (0xE0 0xBA 0xA3)
  • ் = 3 bytes (0xE0 0xAE 0x8D)
  • ட = 3 bytes (0xE0 0xAE 0x9F)

The cluster ண்ட takes 9 raw bytes across 3 Unicode characters!

The Tokenizer Dilemma

A standard naive tokenizer starts with single bytes or single characters. It would chop ண்ட into 3 or 4 separate tokens.

A single short sentence would burn through 40 to 60 tokens, making language models slow and expensive.

In vocab.rs, this repository pre-generates all 528 conjunct stems (23 consonants × 23 consonants) right into the base vocabulary before BPE training starts.

Result: ண்ட is recognized as one single token immediately, cutting token counts across Tamil corpora without wasting the BPE merge budget.
