Lesson 0006

Regex Quantifiers and Grouping by Example

Concrete examples showing what "+", "(?: ... )", and "\p{M}*" do, and what breaks without them.

Step 6 of 13. The pipeline. Quantifiers, groups, and the missing pipe that broke it.

1. The Plus Symbol: + (The Glue)

Without +, a regex matches only one character and stops.

Example: Matching digits in "12345"

  • Pattern \p{N} (no plus): Matches "1", then "2", then "3"... producing five separate chunks.
  • Pattern \p{N}+ (with plus): Matches "12345" as one single chunk.

The plus means: "Must appear at least once, and keep eating matching characters until a non-matching character appears."

2. The Shipping Box: (?: ... ) (Grouping)

In math, parentheses change what a multiplier applies to: 3 × a + b is not the same as 3 × (a + b).

Regex works the same way:

Example: Trying to match "hahaha"

  • If you write ha+: The + only applies to the letter right before it (a).
    Result: Matches "h" followed by many "a"s ("haaaaa"). It will not match "hahaha".
  • If you put them in a box: (?:ha)+: The + now applies to the entire pair "ha".
    Result: Matches "haha", "hahaha", "hahahaha".
Why the ?: inside (?: ... )?

In standard regex, plain parentheses (...) tell the computer to save whatever matched into a numbered variable for later use. This is called a "capturing group" and burns extra CPU time and memory.

Adding ?: tells the regex engine: "This is just a grouping box to apply the + operator. Do not waste CPU cycles saving capture variables."

3. The Backpack: \p{M}* (Optional Marks)

Remember: \p{M} is a Mark (pulli dot ் or vowel sign ா, ி, ீ...).

What does the asterisk * mean? It means zero, one, or more.

Look at three real Tamil consonants in text:

  1. க (ka) -> 1 base consonant, 0 marks.
  2. கா (kaa) -> 1 base consonant, 1 vowel mark (ா).
  3. க் (k) -> 1 base consonant, 1 pulli mark (்).

Why can't we use + instead of *?

  • If we wrote \p{M}+: The mark would be mandatory.
    கா and க் would match, but plain க would fail because it has 0 marks!
  • If we left out \p{M} entirely:
    The regex would match க, but would leave the vowel sign ா or pulli ் behind as an orphaned character.
  • With \p{M}*:
    If a mark exists (கா, க்), it is scooped up. If no mark exists (க), it still matches cleanly.

4. Putting All Three Together

Now look at the combined Tamil pattern:

(?: [\p{Lt}\p{Lm}\p{Lo}] \p{M}* )+
  1. [\p{Lt}\p{Lm}\p{Lo}] \p{M}* = One syllable (one Tamil base letter + its optional mark backpack).
  2. (?: ... ) = The box holding the syllable definition together.
  3. + = Repeat for 1 or more syllables to scoop up the entire word!
