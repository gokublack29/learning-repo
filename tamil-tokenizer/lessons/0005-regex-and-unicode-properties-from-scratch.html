Lesson 0005

Regex and Unicode Properties from Scratch

A complete zero-background guide to regular expression symbols, Unicode categories, and the exact pretokenizer pattern.

Step 5 of 13. The pipeline. What the Unicode categories mean.

1. What is a Regular Expression (Regex)?

A regular expression is a formula that describes a shape of text rather than an exact word.

  • Normal search: Find the exact string "வணக்கம்".
  • Regex search: Find "an optional space, followed by any Tamil consonants, each carrying its attached vowel signs".

To read any regex, you only need to memorize six basic symbols:

|
OR operator

Matches the pattern on the left OR the pattern on the right. cat|dog matches either "cat" or "dog".

?
Optional (0 or 1 time)

The character right before ? is optional. ? means "match a space if one exists, otherwise keep going".

*
Repeat (0 or more times)

Matches zero, one, or twenty times. a* matches nothing, "a", "aa", or "aaaa".

+
Repeat (1 or more times)

Must appear at least once, and repeats as long as matching characters continue. a+ matches "a", "aa", but never empty text.

[ ]
Character Set (Pick any one)

Matches any single item inside the brackets. [abc] matches an "a", a "b", or a "c".

(?: )
Grouping Container

Bundles multiple pieces together so repetition operators (like +) apply to the whole group as a single unit.

2. What are Unicode Properties (\p{...})?

Unicode assigns every character on Earth an official tag describing its linguistic role:

Symbol Category What it matches
\p{L} Letter Any letter in any language (English, Tamil, Hindi, Greek)
\p{Lu} Letter, uppercase Capital letters only (A, B, C)
\p{Ll} Letter, lowercase Small letters only (a, b, c)
\p{Lo} Letter, other Tamil consonants & independent vowels! (Tamil has no upper or lower case)
\p{M} Mark (combining) The pulli dot (்) and all vowel signs (ா, ி, ீ, ு...)
\p{N} Number Digits (0-9, Tamil digits ௦-௯)
\p{P} Punctuation Punctuation marks (, . ! ? : -)

3. Dismantling the Tamil Regex Step by Step

Now look at line 25 of pretokenizer.rs:

| ?(?:[\p{Lt}\p{Lm}\p{Lo}]\p{M}*)+

Here is what happens left to right:

  1. |: Separator meaning "OR match this alternative".
  2. ?: If there is a space before the word, capture it with the word.
  3. (?: ... )+: Repeat the syllable cluster inside as many times as needed to capture the entire word.
  4. [\p{Lt}\p{Lm}\p{Lo}]: Matches one base Tamil letter (e.g. consonant க or vowel அ).
  5. \p{M}*: Matches zero or more combining marks immediately following that letter. If the letter has a pulli (்) or a vowel sign (ா), it is scooped into the cluster.
Trace on the word "வணக்கம்" (vanakkam)

The regex steps through each syllabic cluster:

  1. வ: 1 letter + 0 marks (matches!)
  2. ண: 1 letter + 0 marks (matches!)
  3. க்: 1 letter (க) + 1 mark (்) (matches!)
  4. க: 1 letter + 0 marks (matches!)
  5. ம்: 1 letter (ம) + 1 mark (்) (matches!)

The outer + ties all five clusters into the single pretokenized word chunk: "வணக்கம்".
